# 울산대 ICT융합학부 교과과정

울산대학교 미래엔지니어링융합대학 **ICT융합학부**의 교육과정·트랙·교수진을
한 화면에 모은 웹 서비스.

ICT융합학부는 2025년 글로컬대학30 학사구조 개편으로 신설됐습니다.
1학년은 트랙 구분 없이 학부 공통과정을 듣고, 2학년부터 5개 트랙
(컴퓨터공학 · 인공지능 · 산업ICT공학 · 산업안전공학 · 데이터응용수학)
가운데 기본트랙을 고릅니다. 화면 구성도 그 순서를 따릅니다.

## 시작하기

```bash
pnpm install
cp .env.example .env
pnpm dev
```

기본 주소: http://localhost:5173

**인증키 없이도 전부 동작합니다.** 학부 정보는 모두 정적 데이터라 네트워크를 타지 않습니다.
`/research`(KCI 논문 검색) 한 화면만 오픈API를 쓰고, 키가 없으면 검색을 막고 발급 방법을 안내합니다.

| 변수 | 설명 |
| --- | --- |
| `VITE_DATAGO_SERVICE_KEY` | 공공데이터포털 일반 인증키(디코딩된 키). KCI 논문 검색에만 쓰임 |
| `VITE_OPENAPI_BASE_URL` | 오픈API 경로. 개발 중엔 비워둡니다 |

오픈API는 브라우저에 CORS 헤더를 주지 않아 `vite.config.ts` 의 프록시가 중계합니다.
배포본에서는 이 프록시가 없으므로 `vercel.json` 의 리라이트가 같은 역할을 합니다.

## 배포

Vercel에 정적 빌드로 올립니다. 리포지토리 루트가 곧 앱이라 Root Directory 설정은 필요 없고,
`pnpm build` → `dist` 는 Vite 프리셋이 알아서 잡습니다. 설정은 [`vercel.json`](vercel.json) 두 줄뿐입니다.

| 리라이트 | 이유 |
| --- | --- |
| `/openapi/datago/*` → `apis.data.go.kr` | 개발 서버 프록시를 대신한다. 공공데이터포털은 CORS 헤더를 주지 않는다 |
| 나머지 전부 → `/index.html` | `/curriculum` 에서 새로고침해도 404 가 나지 않게. 실제 파일이 있으면 그쪽이 먼저다 |

**인증키는 배포 환경변수에 넣지 않는 것을 권합니다.** `VITE_` 로 시작하는 값은 빌드할 때
자바스크립트 번들에 그대로 박혀서 누구나 읽을 수 있습니다. 키가 없으면 `/research` 는
"인증키가 필요합니다" 안내를 띄우고 나머지 화면은 전부 정상입니다. 검색까지 열려면
키를 서버에서 붙이는 서버리스 함수를 두는 편이 안전합니다.

## 화면을 쓰는 법

### 주소로 남는 선택

트랙과 유형은 쿼리로 남습니다 — `?track=AI&variant=통합`. 새로고침해도 같은 화면이 열리고,
링크를 그대로 보내면 상대도 그 트랙을 봅니다. `replace` 로 갱신해서 트랙을 여러 번 눌러도
뒤로가기가 쌓이지 않습니다. 값이 이상하면 기본값(컴퓨터공학 · 기본트랙)으로 되돌립니다.

### 검색과 바로가기

- 과목명·과목코드 검색과 이수구분(전필·전선·교필·교선) 필터가 두 표에 함께 걸립니다.
- 조작 줄은 태블릿(1024px) 이상에서 헤더 아래 고정됩니다. 좁은 화면에서는 여러 줄로 접혀
  본문을 다 덮기 때문에 저절로 풀립니다.
- 조작 줄의 **바로가기** 칩과 트랙·유형 전환은 해당 섹션으로 스크롤합니다. 헤더와 고정된
  조작 줄의 높이를 그때그때 재서 제목이 가려지지 않게 띄웁니다.

### 움직임

지표 숫자는 화면에 들어올 때 목표값까지 굴러가고(`useCountUp`), 섹션은 위에서부터 차례로
옅게 떠오릅니다.
**시스템에서 '움직임 줄이기'를 켜 두면 전부 생략하고 결과만 즉시 보여줍니다.**

### 교육과정 데이터에 대해

| 데이터 | 출처 | 방법 |

**UWINS 가 정본입니다.** 이수체계도 이미지와 실제 개설 과목명이 다릅니다 —
이미지의 "데이터 사이언스"는 실제로 `EN0078 AI데이터사이언스`, "논리회로"는
`EN0097 디지털공학`입니다. 화면은 UWINS 를 먼저 보여주고, 이수체계도는
4년 로드맵으로 따로 싣습니다.

ICT융합학부는 2025년 신설이라 **2026학년도 기준으로 1·2학년만 개설**돼 있습니다.
3·4학년은 이수체계도의 계획으로만 존재하며, 화면에도 그렇게 적혀 있습니다.

산업ICT공학·산업안전공학 트랙의 이수체계도에는 학점 표기가 없어 `credits: null` 로
두고 화면에도 찍지 않습니다. 0학점 과목(졸업작품 등)과 구분됩니다.

## 폴더 구조

```
src/
├─ data/          학부 사실 데이터 — 전부 출처 확인된 실제 값
│  ├─ school.ts             학부 기본 정보
│  ├─ curriculum.ts         5개 트랙 이수체계도 + 이수 규정
│  ├─ generalEducation.ts   교양 영역·과목
│  ├─ faculty.ts            교수진 24명
│  ├─ publicData.ts         등록금 실측값
│  └─ officialCurriculum.json  UWINS 개설 교과목
├─ api/           axios 인스턴스 + 포털 응답 봉투 처리
├─ services/      오픈API — 현재 KCI 논문뿐
├─ hooks/         useCountUp — 숫자 굴리기
├─ components/
│  ├─ common/     Chip · Toolbar · Section · StatCard · CountUp · DataTable
│  │              · QueryState · ScrollTopButton
│  └─ layout/     RootLayout
├─ pages/         라우트 단위 화면 (index.tsx + style.css.ts)
├─ styles/        theme · font · flex · spacing · screen · elevation · layout · global
└─ utils/         숫자·금액 표기 · 움직임(스크롤·움직임 줄이기)
```

`@` 는 `src/` 를 가리킵니다.

## 디자인

강조색은 학부 로고에서 가져온 **`#00A663`** 하나뿐입니다(`theme.accent`).
나머지는 중립 회색이고, 상태색(경고·오류·정상)만 따로 씁니다.

도구처럼 보이도록 스케일을 눌렀습니다. 화면 제목 20px, 라벨 13px, 그림자는
`0 1px 2px rgba(17,17,17,.05)` 하나뿐이고 면은 1px 테두리로 나눕니다.
선택 UI는 전부 회색 트랙 위의 알약 칩(`Chip`)이고, 조작은 본문 맨 위 `Toolbar` 한 줄에 모읍니다.
색은 데이터와 상태에만 쓰고 나머지는 중립 회색으로 물러납니다.
